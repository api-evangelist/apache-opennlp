TThe Apache OpenNLP library is a machine learning based toolkit for the processing of natural language text. The Apache OpenNLP team is pleased to announce the release of Language Detector Model 1.8.3 for Apache OpenNLP 1.8.3. The Language Detector Model can detect 103 languages and outputs ISO 639-3 codes.
